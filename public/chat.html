Sampler & Context Controls
Balance creative unpredictability against narrative coherence. These sampling parameters are passed to the model on every inference request.
Temperature 0.85
Controls randomness. Lower (0.4–0.7) is focused and deterministic; higher (0.8–1.1) is creative and descriptive.
Top P (Nucleus Sampling) 0.95
Cumulative probability threshold. Only the smallest set of tokens whose cumulative probability exceeds P are considered.
Min P 0.05
Dynamic probability cutoff relative to the most likely token. Filters out nonsensical tail tokens without flattening prose.
Max Output Tokens 1500
Maximum token ceiling per generated turn. 1500 tokens ≈ 4–5 rich literary paragraphs.
Frequency Penalty 0.25
Penalizes words based on frequency in output so far. Higher values reduce repetitive verbal tics.
Presence Penalty 0.15
Penalizes tokens that have already appeared once, encouraging new topics and vocabulary.
Max Context Budget (Tokens) 32768
Context window limit. Triggers continuity ledger folding when active history approaches this budget.
